Media

Centered Image (Default)

Left Aligned with Text Wrap

<figure class="left">
  <img src="photo.jpg" alt="...">
</figure>
<p>Text wraps around...</p>

This text wraps around the left-aligned image. When you use the left class on a figure, it floats to the left and allows text to flow around it naturally. This creates a magazine-style layout that works well for articles and blog posts.

Customizing

Override any CSS variable in styler.css:

/* In styler.css after the imports */
:root {
  --readable-width: 40rem;  /* narrower content */
  --base-font-size: 18px;   /* smaller text */
  --box-radius: 0.5rem;     /* rounder corners */
  --primary: #8b5cf6;       /* purple primary */
  --bg: #fefefe;            /* off-white background */
}

.dark {
  --bg: #0a0a0a;            /* near-black for dark mode */
}
