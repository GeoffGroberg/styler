Customizing

Include your custom stylesheet after base.css to override variables:

:root {
  --readable-width: 40rem;  /* narrower content */
  --base-font-size: 18px;   /* smaller text */
  --box-radius: 0.5rem;     /* rounder corners */
  --primary: #8b5cf6;       /* purple primary */
  --bg: #fefefe;            /* off-white background */
}

.dark {
  --bg: #0a0a0a;            /* near-black for dark mode */
}

Left Aligned with Text Wrap

<figure class="left">
  <img src="photo.jpg" alt="...">
</figure>
<p>Text wraps around...</p>

This text wraps around the left-aligned image. When you use the left class on a figure, it floats to the left and allows text to flow around it naturally. This creates a magazine-style layout that works well for articles and blog posts.

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur.

On smaller screens (below 50rem), floated images automatically become full-width and centered to ensure readability on mobile devices.

Right Aligned with Text Wrap

Similarly, using the right class floats the image to the right. Text flows around on the left side. This creates a nice visual rhythm when alternating between left and right aligned images throughout your content.

The responsive behavior happens automatically without any additional classes or JavaScript. Images shrink gracefully and reflow as the viewport changes.
